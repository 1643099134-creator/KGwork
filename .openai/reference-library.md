# 常用资料库

`/references?team=…`。侧栏单入口，类别全部放在页面顶部；分类由固定初始分类和已保存便签中的自定义分类构成。每个类别是一组独立的便签视图。

数据存储在 D1 `reference_cards` / `reference_usage`，不使用浏览器存储保存资料。用户在对话中给出的真实凭据、账号和财务数据未写入源代码，也没有自动导入生产数据库。

- 新资料默认 `private`，仅创建者可读，管理员没有隐式读取私密便签的权限。
- 可显式授予团队、指定成员或既有文件群组读取权；只有创建者可修改权限或正文。获得访问权的成员可以读取完整资料；没有访问权的人无法获取列表正文或详情。
- 按用户明确要求取消内容遮挡：获得访问权的人可直接阅读正文和全部字段；正文和字段参与其可访问资料内的搜索。旧记录的 sensitive / secret 标记不会继续遮挡内容，不批量改写任何记录或分享范围。详情端点仍逐次校验团队、可见范围、群组成员、回收站状态。
- 独立字段支持直接查看和复制；复制全部资料包含所有字段和正文。普通网址字段拒绝凭据型自动登录链接；这类链接可作为正文保存，不生成直接打开入口。
- 私密便签不是专用密码保险库：没有新增客户端端到端加密能力。依赖托管数据库保护和服务端授权。
- 置顶/最近使用按访问者分别记录，删除为软删除，仅创建者可恢复；修改采用 version CAS。
- 粘贴整理在客户端按分隔线拆分、用简单关键词建议分类，每条经人工核对再单独保存。不会发送给 AI 服务，不自动判定密码/银行信息有效性，不自动合并重复项。

验证：`.sites-runtime/test-references.cjs` 覆盖私密/管理员隔离、指定分享和撤销、授权人可读全部内容及旧隐藏标记兼容、详情权限、只读角色、个人置顶、CAS、回收站、危险网址和草稿默认权限。
