# 工作区首页

`/` 与 `/?team=…` 默认进入 Dashboard；原始便签页面使用 `/?view=all`，其余 view/area/members 参数仍进入原 Notebook，任务/文稿/权限入口不变。侧栏新增一个工作区入口。

## 内容与操作

- SSR 复用已有 workspace 数据（任务、成员、通知等），首屏不重复请求任务；其余模块经 `/api/dashboard?extras=1` 补齐。
- 页面显示个人待办、待验收、逾期、伙伴与管家独立未读；工作台筛选今日/全部/进行中/待验收。
- 快捷弹窗可保存便签、本人任务；管理员可派发到成员或先待分配。复用 workspace save，包括版本、成员权限、任务计划、通知和验收规则。
- 任务开始/完成与管理员验收可直接操作。资料附件与复杂安排从任务详情继续处理。聊天打开既有快捷抽屉，不自动发送消息。
- 今日独立日程与任务分别呈现；任务的截止日期继续由现有日历合并显示。
- 团队动态按可查看的任务负责人汇总；项目只返回已有权限项目，节点关联任务仍要符合任务 ACL。
- 常用资料只选择本人置顶/最近使用且仍有权限的便签；首页展示名称，可直接复制完整资料。最近文件提供受保护的预览/下载，不包含 R2 object key。
- 45秒可见页轮询，切换团队丢弃旧请求结果；伙伴未读使用既有6秒共享 feed。刷新错误保留现有已加载内容，部分模块失败可单独提示。
- 今日/截止时间按北京时间计算；默认无写权限的账号只能查看。

验证：`test-dashboard.cjs` 在真实 SQLite schema/mock R2 上覆盖匿名、团队/任务权限、私密资料、文件、日历范围、项目关联节点任务隔离和 extras-only 首屏补充。本地浏览器验证首页新增本人任务、开始任务、回到原便签页与工作区往返。未在生产环境创建测试任务或修改真实团队数据。
